## About

Astro Raider is a 2D pixel art roguelike endless shooter built in Godot 4. You drill through destructible terrain, collect crystals, and spend them at the Generator to unlock and upgrade perks — all while defending against escalating waves of enemies and boss encounters.

The game features a handcrafted progression loop where every run pushes you to make meaningful build decisions across passive, activation, and ultimate perk categories.

## Features

- Destructible terrain — drill through tiles to mine crystals and carve your own path.
- Perk system with passive, activation (Q/E/C), and ultimate (X) categories and rarity-weighted selection.
- Combat with ranged weapons, drill damage, knockback, shields, and status effects.
- Enemy AI with distinct behaviors, environmental hazards, and multi-phase boss encounters.
- Procedurally generated environments with per-planet configurations.
- Custom shaders — animated title screen nebula, LUT player recolor, hexagon shield, projectile trails.
- Localized text for English and German.
